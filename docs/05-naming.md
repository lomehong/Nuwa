# 05 · 命名宇宙与 Logo

状态：已定稿（2026-10-15）。备选名与其落选理由一并存档。

## 总名：女娲（Nuwa）

天有裂缝，女娲炼五色石以补之。中文神话中唯一的"修补创世神"——与"给系统提交修复补丁"字面同构。

- 英文代码名：`nuwa`（仓库、服务端主二进制）
- 副题：**补天**

## 组件命名宇宙

| 组件 | 神话名 | 代码名 | 神话职能 → 系统职能 |
|---|---|---|---|
| 现场采集 SDK | 青鸟 | `qingniao-go` / `qingniao-java` / … | 西王母信使，"青鸟殷勤为探看" → 各系统的报信使者，按语言各写一枚 |
| 问题单库 | 山海经 | `shanhaijing` | 天下异兽图鉴 → 所有系统 bug 的去重目录：每只"怪兽"（问题单）记录在案 |
| 补丁单元 | 五色石 | `wuse`（补丁格式/元数据） | 炼石补天的材料 → 一次修复产出的补丁及其验证证据；五色可映射问题等级/技术栈 |
| 修复 runner | 应龙 | `yinglong` | 助大禹治水的翼龙，"画地成河" → 一个补丁把问题洪流疏导成河；按技术栈划多个 runner |
| 验证探针 | 待定 | — | 现场预定义验证脚本的下发执行体（命名与设计见 open-items） |

## 介绍文案（对外一句话版）

> **Nuwa（女娲）**——一个自愈式修复 Agent。它像女娲补天一样工作：青鸟（现场采集 SDK）巡行于你的各个系统，把运行时的裂缝报上山海经（问题单库）；女娲炼五色石为每一道裂缝定制补丁，由应龙（修复 runner）验证后化作 PR，合入你的仓库。天补好了，青鸟继续巡逻。

## 落选备选（存档）

| 名 | 落选理由 |
|---|---|
| 谛听（Diting） | "辨真伪"与指纹去重高度契合（辨真假美猴王 = 辨真 bug 与噪音），但神话里只诊不修，组件宇宙不完整；作为强备选保留 |
| 扁鹊（Bianque） | 四诊（望闻问切）可映射四类采集探针、病历=问题单、药方=补丁，映射极工整；但为历史人物而非神话，`bianque` 拼写不友好 |
| 大禹（Dayu） | "疏而不堵"契合 PR 分流，代码名极短；但治水叙事偏"控制"而非"修复"，中文语料撞名多 |

命名灵感来源：中国传统文化与神话（女娲补天、青鸟传信、山海经异兽、应龙画地）。
